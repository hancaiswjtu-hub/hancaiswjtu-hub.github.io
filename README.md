# 蔡晗教授个人学术主页

响应式静态个人主页，无需安装依赖或构建工具。

## 使用

直接打开 `index.html`，或在当前目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## GitHub Pages

项目可直接从仓库根目录通过 GitHub Pages 发布，无需构建命令。

## 内容来源

页面中的个人简介、研究方向、学术经历、代表论文与招生方式整理自西南交通大学教师个人主页公开信息：

- https://faculty.swjtu.edu.cn/caihan/zh_CN/index.htm
- https://faculty.swjtu.edu.cn/caihan/zh_CN/lwcg/386613/list/index.htm

头像使用学校教师主页公开资源。若离线浏览或远程资源不可用，页面会自动显示姓名缩写占位图。
